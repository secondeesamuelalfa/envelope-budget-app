# 💰 Envelope Budget App

A vintage-themed, responsive web application that helps users manage their monthly budget using the envelope budgeting method.

🔗 **[Live Demo](https://secondeesamuelalfa.github.io/envelope-budget-app/)**

## 🚀 Features

- **Envelope Budgeting System**: Separate expenses into categories (Food, Utilities, Entertainment) with a fixed Rent input
- **Dynamic Entry Management**: Add unlimited expense entries to each category
- **Real-Time Calculations**: Instantly calculates remaining budget or overspending
- **Vintage Envelope Design**: Unique UI inspired by physical envelope budgeting with kraft paper texture and typewriter fonts
- **Responsive Design**: Works seamlessly on mobile and desktop
- **Input Validation**: Prevents invalid inputs (scientific notation, special characters)

## 🛠️ Technologies Used

- **HTML5** (Semantic structure with fieldsets and legends)
- **CSS3** (Advanced techniques: `clip-path`, `repeating-linear-gradient`, CSS custom properties, Google Fonts)
- **Vanilla JavaScript (ES6+)** (DOM manipulation, dynamic HTML generation, input sanitization)

## 🎨 Design Highlights

- **Envelope Flap Shape**: Created using CSS `clip-path: polygon()`
- **Kraft Paper Texture**: Achieved with `repeating-linear-gradient`
- **Typewriter Aesthetic**: Google Fonts (`Special Elite` for headings, `Inter` for body text)
- **Stamp-Inspired Color Scheme**: Red "stamp" color for primary actions
